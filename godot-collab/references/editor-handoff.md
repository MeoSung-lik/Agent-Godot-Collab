# 编辑器交接：留给人做的事怎么交代

原则：添加节点、调整大小/位置/缩放、场景摆放这类编辑器内操作，**优先交给用户手动完成，或由 AI 做成静态预制件场景**（见 prefab-first.md）——两条路都保证用户后续能在编辑器里继续调整。需要人动手时，交代必须可执行。

## 交接单写法

编号步骤 + 精确数值 + 指明在哪里做（哪个场景哪个节点）。示例：

1. 打开 `scenes/大厅.tscn`，选中 `登机口` 节点
2. Inspector 把「每日免费次数」设为 3
3. 把 `触发区` 摆到门框处（参考坐标 x=-12.4, y=0, z=8.0，以观感为准微调）
4. 保存场景后运行预览确认

## 常见留人操作

- **场景摆位**：AI 给参考坐标与生成好的预制件，人以观感为准微调摆放
- **材质/贴图/配色定稿**：AI 出可选方案（探针截图对比），人拍板
- **地形雕刻、烘焙**
- **动画关键帧微调**：AI 出可用动画，人在动画面板精调
- **UI 布局精调**：AI 出可用布局，人在编辑器里自由摆放（注意：容器换类型时脚本里的 typed `@onready` 声明要同步改，否则运行崩——细节见 godot-dev/references/scenes-tscn.md）

## 让人可调的接口设计

- 每个暴露参数：中文名 + 合理默认值 + 必要时 setter 校验范围
- 用 `@export_category`/`@export_group` 按功能分组
- 代码新增 `@export` 后，在交接单里列出「Inspector 新增了哪些字段、建议值」

## 与用户手调内容的共存

- 用户在编辑器里手加的节点、手调的覆盖值是**权威**——代码与批量工具不得覆盖。
- 批量工具重写场景文件后**必须 diff 实例属性行**（工具会重写属性行，带引号的中文覆盖最易被丢，丢了就是静默回退默认值）。
- 场景合并/分支切换后跑结构探针秒验节点完整性——细节见 godot-dev/references/editor-project.md。
- 观感类验收交给人：AI 用探针截图供快速过目，最终以编辑器/真机实机为准。
