# Godot 人机协作开发

把 Godot 游戏开发拆成两条线：**编辑器侧（人）**与**代码侧（AI）**，用确认制把两边接起来。目标：所有可调的东西都能在编辑器里调，所有逻辑都能被代码可靠执行，中间不留模糊地带。

## 角色分工

**人（项目所有者，在编辑器里工作）**
- 需求：逐步解释想要什么；对不明确处拍板（AI 给选项+推荐，人定）
- 编辑器操作：搭场景、摆节点、调位置/大小/缩放/材质、地形雕刻烘焙、Inspector 调参
- 观感验收：画面、手感、演出——截图代替不了人的眼睛，最终以编辑器/真机实机为准
- 流程决策：何时提交、打包、提审

**AI（代码侧 + 产线）**
- 脚本逻辑、状态管理、事件触发、流程调度
- 批量生成静态预制件（产物是编辑器可调的 .tscn）、写场景接线
- 探针/无头测试/截图自测与 bug 修复迭代
- 数值接线：读配置表，把可调项 `@export` 暴露

## 协作流程（每个功能一轮）

1. **澄清需求**：用户逐步解释，实现按已确认内容推进。不明确之处记录成问题清单向用户确认，不用猜测替代；未被明确说明的规则/流程/交互/数值/异常处理/自动补全逻辑一律不加（不做兜底设计）。
2. **方案确认单**：动手前列出（模板见下）→ 用户确认 → 统一执行，不边做边扩。
3. **实现**：只做已确认范围。设计遵循**预制件静态优先**（references/prefab-first.md）；写代码/改场景前查 godot-dev 坑库（路由表见下）。
4. **自主自测**：实现完成后的运行预览、探针、测试与 bug 修复迭代自主进行，无需逐次确认；发现超出已确认范围的新增功能 → 停下先确认，并在验收时如实报告。
5. **验收报告 + 编辑器交接**：如实报告（模板见下）；留给人做的编辑器操作写成可执行步骤（references/editor-handoff.md）。

### 方案确认单模板

1. 准备修改或新增哪些文件
2. 准备创建或调整哪些场景/节点
3. 准备新增哪些脚本、组件、`@export` 参数
4. 是否需要运行 Godot（导入资源/生成文件/预览）
5. 哪些编辑器操作留给人手动完成（附操作步骤与具体数值）

### 验收报告模板

1. 实际修改了哪些内容
2. 哪些来自已确认需求（区分清楚：确认需求 / 自主修复的 bug / 未确认的新增——最后这类不应存在，若发生了必须显式标出）
3. 运行自测结果与修复的 bug（如实，失败就是失败）
4. 需要用户继续解释或确认的点

## 自主自测的边界

- **可以自主**：运行预览、无头测试、探针、截图、修 bug、回归已有测试、搭建调试场景（统一放专门调试场景，不散落业务场景）。
- **必须停下确认**：新增功能/系统/UI 文案、玩法数值决策、删除或覆盖用户手调的编辑器内容、引入新资源/插件/包。
- **拍板文化**：给选项时附推荐项和理由，推荐项放第一个；用户未答复时按推荐执行，并在报告中注明「按推荐执行，待追认」。

## 设计约定（代码侧）

- **单一职责**：控制逻辑按职责拆分为多个节点/脚本/资源，不造巨型上帝脚本。
- **数值唯一来源**：配置表/资源文件；脚本不硬编码常量（表规范见 references/prefab-first.md）。
- **全局/跨场景状态用 Autoload**（注册名必须 ASCII），不用 static 字段；跨场景常驻对象挂 root 或 Autoload。
- **查找用 group**（`add_to_group` + `get_first_node_in_group`），不按名递归遍历。
- **指令驱动**：硬编码节点指令用通用解析器（`Dictionary[String, Callable]` + await），指令格式 `[动作名]|[参数1]|[参数2]…`——新增演出/流程指令只加 Callable 项，不改 switch。
- **调试集中**：所有测试、debug 脚本统一放专门调试场景（如 DebugLog.tscn），需要调试能力时实例化它，不在业务场景散落调试代码。
- **命名**：节点名/`@export` 参数/调试文本用中文；类/函数/变量名英文常规风格；强类型（GDScript 坑见 godot-dev/references/gdscript.md）。

## 禁区

- 不擅自扩展玩法、不擅自补系统、不擅自加 UI 文案。
- 不引入与当前需求无关的资源、插件或包。
- 不做兜底设计：没有被明确说明的异常处理、自动补全、防御逻辑不加。
- 不在代码里硬编码位置/大小/缩放，不运行时覆写编辑器配置（细则见 references/prefab-first.md）。
- 修改/删除用户在编辑器里手搭的内容前先确认。
