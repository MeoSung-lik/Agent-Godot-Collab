# 物理与碰撞（Jolt）· Terrain3D 地面逻辑

项目背景：Jolt 物理 + Terrain3D 起伏地形（可挖坑、坡面、竖向变化）。无 Terrain3D 的项目跳过第三、四节的 Terrain3D 专属条目，其余通用。

## 物理体缩放（最容易全链翻车）

- 物理体带非 1 缩放全链不可靠：0.3 缩放 CharacterBody 与地形碰撞的**一切交互失效**（move_and_slide 接触 / is_on_floor / 射线 / depenetration 全坏），1.0 body 同点正常。缩放放视觉子节点，碰撞 shape 用真实尺寸。
- 预制件根用 Node3D，物理体作子节点且自身缩放恒 1——任何非统一缩放都会触发编辑器「缩放不统一，这个节点很可能无法正常工作」警告，且 Jolt 对物理体非均匀缩放不可靠。碰撞需求由子物理体继承父级缩放满足（盒子等可缩放形状在非均匀缩放下仍精确）。
- 转换后射线/物理查询返回的 collider 是**子物理体**而非原根节点——依赖 collider 身份的代码取 `collider.get_parent()`。

## Jolt 特性

- `physics/jolt_physics_3d/limits/max_bodies` 默认 10240，大地图超限后**部分 StaticBody 创建失败** → 地面缺失、AI 集体不激活——超限是静默的。该键不在 get_property_list 里，要直查 project.godot。
- 休眠刚体直接改位 / 解冻循环传送都**不触发 Area3D 重叠**；headless 下玩家传送 + Area 扫过也可能不刷新——验证吸附/拾取链要么让物体出生就在探测区内、要么手动调进入函数，别当游戏 bug。
- CCD 是白扔的开关：初速 ≤3.5m/s 的小物体根本不需要 continuous_cd，白吃物理开销。
- move_and_slide 高速下坠会**隧穿地形薄面**（is_on_floor 不触发、钻地下）——下落段每帧向下短射线预探测命中即贴地收口；安全网=超时后**从全图最高点上空重新向下探测**（已在地下时，从宿主位置向下打不到地面——地面在头顶）。
- 探测射线起点低于目标地形时扎进体内，`hit_from_inside` 默认 false 穿透不命中 → 起点抬升 `maxf(原点y, 数据高度) + 5`。直测射线的 collision_mask 必须显式设（默认全层会被探针自放的道具假命中）。
- 射线类测试前先确认可命中体实际尺寸——碰撞胶囊远小于视觉模型时，瞄「胸口 0.9m」会从头顶掠过命中墙/地面（症状：take_damage 不触发、验路"无阻挡"）。

## Terrain3D

- **物理碰撞与视觉地形可能大面积不符**：物理射线在大片区域只命中错误低平面，而 `get_height()` 数据高度与视觉同源**永远可靠**——空投/击飞/贴地类「大范围瞬移式落点」最易暴露；逐帧接触的活动区域正常。再撞「角色/物体沉地」先查这里。
- collision_mode 枚举：0=DISABLED / 1=DYNAMIC_GAME（仅游戏 + **仅相机周围 collision_radius=64m**，默认）/ 2=DYNAMIC_EDITOR / 3=FULL_GAME（全区域每区一块）/ 4=FULL_EDITOR。DYNAMIC 下全图绝大多数远处射线必扑空（相机在原点时 226m 外无命中）。
- collision_mode 运行时切换**不清已建碰撞**——测「无碰撞环境」必须 free 旧实例换 DISABLED 新实例。
- 无活动相机时 Terrain3D 直接停 _physics_process（_grab_camera 报错）。
- 陡坡上碰撞三角面 vs 数据插面差分米级（59° 坡实测差 1.56m）。
- `get_height()` 范围外/地形缺失返回 **NAN**——统一 NAN 防御，无效时明确回退（回原位/纯射线），不猜值。
- Terrain3D 不走卡通材质转换：材质饱和度对地形无效——调色只能靠环境级饱和/对比和光照。

## 落面公式（贴地/落地类逻辑的定案）

落点探测 = `maxf(物理射线命中 y, 地形数据高度)`：

- 数据高度**带区间约束**（沿弹道方向限制在落点附近取样）——无约束版会在弹道飞越中途高地时提前吸落（实测偏差 65.8m）。
- 数据高度是 heightmap **不含建筑**——数据高度只用于抬起点/兜底，落点仍以射线命中为准（建筑内摆点会被室外地形数据吸上）。
- 陡坡碰撞面沉差由 maxf 根除；命中更高的楼顶/桌面不受影响（数据高度=视觉面）。
- 无命中（NAN/扑空）时明确不钳制、不生成——不要落到固定高度。

## 禁平地假设（总则）

凡「离地高度」一律以脚下地面为基准：物理帧向下射线（或地形高度查询）取地面再加相对偏移。写新逻辑自问：「角色在坑里、坡上、楼顶时还对吗？」固定世界高度（`y < 常量` 钳制、`y = 常量` 生成/悬浮基准、把出生点的地面高度缓存成长期常量）都是雷——相机最低高度锁地平面在坑里会把镜头压回地平面，程序化机位固定高度在丘陵会扎进沙丘。
